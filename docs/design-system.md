# Дизайн-система Vidora

Небольшая собственная дизайн-система без UI-библиотек. Цель: раскладка и ощущение как у
YouTube (тёмная тема, шапка с поиском по центру, боковое меню, сетка карточек 16:9, страница
просмотра с рекомендациями справа), но **свой бренд**: название Vidora, свой логотип
(шестиугольник с градиентом и кнопкой play), свои иконки. Логотип, шрифты и иконки YouTube
не используются.

Где лежит: токены в `frontend/src/styles/tokens.css`, база в `styles/base.css`, компоненты в
`frontend/src/components/` (`ui.tsx` + `ui.css`, `Icon.tsx`, `VideoCard`, `Player`, `Comments`, `Layout`).

## Принципы
1. **Только токены.** Компоненты не содержат «магических» цветов и размеров: только
   `var(--color-*)`, `var(--space-*)`, `var(--radius-*)`, `var(--font-*)`. Исключение — данные
   пользователя (цвет аватара канала).
2. **Тема переключается сменой значений токенов**, а не стилями компонентов:
   `:root` — тёмная тема (по умолчанию), `:root[data-theme="light"]` — светлая.
   Выбор хранится в `localStorage` (с try/catch).
3. **Сетка 4 px.** Все отступы кратны 4.
4. **Доступность:** видимый фокус (`--focus-ring`), `aria-label` у иконочных кнопок,
   `role`/`aria-*` у меню, вкладок, прогресса и модалок (нативный `<dialog>`).
5. **CSP без компромиссов:** никаких inline-скриптов. Стили в CSS-файлах, динамика через CSSOM.

### Цвет
| Токен | Тёмная | Светлая | Где |
|---|---|---|---|
| `--color-bg` | `#0f0f0f` | `#ffffff` | фон страницы, шапки, меню |

| `--color-surface-raised` | `#282828` | `#ffffff` | меню, модалки |
| `--color-surface-hover` | `#3f3f3f` | `#e5e5e5` | наведение, трек прогресса |
| `--color-border` / `-subtle` | `#3f3f3f` / `#303030` | `#d9d9d9` / `#e5e5e5` | поля, разделители |
| `--color-text` / `-secondary` | `#f1f1f1` / `#aaaaaa` | `#0f0f0f` / `#606060` | основной и вторичный текст |
| `--color-brand`, `--color-brand-2` | `#ff4e2a`, `#e01e5a` | | градиент логотипа |
| `--color-accent` | `#3ea6ff` | `#065fd4` | ссылки, фокус, активные лайки, кнопка «Далее» |
| `--color-danger` / `success` / `warning` | `#ff4e45` / `#2ba640` / `#f9a825` | | ошибки, статусы |
| `--color-chip`, `-hover`, `-active` | полупрозрачный белый, активный — инверсия | | чипы фильтров |
| `--color-button`, `-hover` | `rgba(255,255,255,.1/.2)` | `rgba(0,0,0,.05/.1)` | вторичные кнопки |
| `--color-primary-button` | `#f1f1f1` | `#0f0f0f` | «Подписаться» (инверсия фона) |

### Отступы, радиусы, типографика, слои
- Отступы: `--space-1..10` = 4, 8, 12, 16, 20, 24, 32, 40 px.
- Радиусы: `--radius-sm` 8 (чипы, поля), `--radius-md` 12 (превью, плеер, блоки),
  `--radius-lg` 16 (модалки, баннер), `--radius-pill` (кнопки, поиск).
- Шрифт: системный стек `Roboto, Segoe UI, Helvetica, Arial` (без загрузки шрифтов с CDN).
  Размеры `--font-size-xs..3xl` = 12, 14, 16, 18, 20, 24, 36. Веса 400 / 500 / 700.
- Раскладка: `--header-height` 56, `--sidebar-width` 240, `--sidebar-mini-width` 72,
  `--watch-secondary-width` 402.
- Слои: `--z-sidebar` 90 < `--z-header` 100 < `--z-menu` 200 < `--z-modal` 300 < `--z-toast` 400.

## Компоненты

| Компонент | Варианты / свойства | Использование |
|---|---|---|
| `Button` | `primary` (инверсия, «Подписаться»), `secondary` (полупрозрачная), `ghost`, `accent` (синяя), `outline-accent` («Войти»), `danger`; `size` sm/md; `icon` | все действия |
| `IconButton` | обязательный `label` (aria-label + title) | меню, закрыть, действия в таблицах |
| `Avatar` | `title` (первая буква), `color`, `size`, `to` (ссылка) | каналы, комментарии, шапка |
| `Logo` | — | шапка, страницы входа |
| `Chip` | `active` | фильтры по тегам, сортировка, вкладки модерации |
| `Menu` | `items` (иконка, текст, ссылка/действие, `danger`), `align`, `header`; закрывается по клику вне и Esc | меню аккаунта, «⋮» у комментариев и видео, сортировка |
| `Modal` | `title`, `footer`, `wide`; нативный `<dialog>`: фокус-ловушка и Esc из коробки | жалоба, сохранение в плейлист, редактирование |
| `TextField` | `label`, `hint`, `error`, `multiline` | все формы |
| `Spinner`, `PageSpinner`, `ProgressBar` | — | загрузка данных, прогресс загрузки файла |
| `EmptyState` | `icon`, `title`, children | пустые списки, 404, «войдите» |
| `Icon` | ~40 собственных контурных глифов 24×24, `stroke: currentColor` | везде |
| `Toast` | `toast(msg)`, `toastError(err)` | ошибки действий |
| `VideoCard` | `grid` (главная), `compact` (рекомендации, плейлист), `list` (поиск, история) | все списки видео |
| `Thumbnail` | 16:9, `object-fit: cover`, бейдж длительности, плейсхолдер со статусом обработки | карточки, студия, модерация |
| `Player` | нативный `<video controls>` + переключатель качества (запоминается), повтор при истёкшей ссылке | просмотр |
| `Comments` | форма с раскрывающимися кнопками, ответы (1 уровень), лайк, меню, «изменено», выделение автора видео | просмотр |
| `Layout` | шапка (меню, логотип, поиск, «Создать», аватар/«Войти»), сайдбар полный / мини / выезжающий | все страницы |

## Раскладка и адаптивность
- **≥ 1312 px:** полный сайдбар 240 px. **800–1312:** мини-сайдбар 72 px (иконка + подпись).
  **< 800:** без сайдбара, меню выезжает поверх. Логотип сокращается до знака.
- **Просмотр:** сайдбар всегда выезжающий (как на YouTube); колонка рекомендаций 402 px
  справа, ниже 1000 px уходит под видео.
- **Сетка ленты:** `repeat(auto-fill, minmax(300px, 1fr))`, расстояние 40/16 px.
- Липкие элементы: шапка, полоса чипов на главной, нижняя панель на странице загрузки.

## Тексты
Интерфейс на русском, склонения через `lib/format.ts` (`1 просмотр`, `2 просмотра`,
`5 просмотров`, `3 дня назад`), числа сокращаются как в оригинале (`1,5 тыс.`, `2,3 млн`).

## Как добавить компонент
1. Взять существующие токены. Если нужного нет, добавить токен в обе темы в `tokens.css`.
2. Состояния: hover, focus-visible, disabled, active через токены.
3. Иконочные кнопки только с `label`.
4. Описать вариант в таблице выше.
